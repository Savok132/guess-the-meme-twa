# 🗿 ЧЁ ЗА МЕМ? (Telegram Web App)

> Интерактивная мемная викторина нового поколения, созданная специально для **Telegram Mini Apps (TWA)**.

Включает самые свежие тренды (Тапай Хомяка, Квадроберы, Скуфы и Альтушки на Госуслугах, Чиназес, Русы против Ящеров) и бессмертную классику рунета (Язь, Кандибобер, Повар спрашивает повара, Идущий к реке, Глад Валакас, Дружко и др.).

---

## 🎮 Возможности игры

- ⚡ **3 игровых режима**:
  - **Быстрый Брейнрот**: 10 динамичных вопросов, таймер 12 секунд, комбо-множители и нарастающий азарт.
  - **Выживание Скуфа**: Игра на выбывание с 3 жизнями до первой серии критических ошибок.
  - **Чья это цитата?**: Викторина по культовым фразам рунета.
- 🔊 **Web Audio движок звуков**:
  - Аутентичный **Vine Boom** (тяжелый суб-басовый удар при ошибке).
  - Звонкие поп-клики, мажорные аккорды правильного ответа, комбо-фанфары.
  - Работает 100% автономно без внешних аудио-файлов и задержек.
- 📳 **Telegram Haptic Feedback**: тактильная отдача на смартфонах при нажатиях, победах и ошибках.
- 🏆 **Система Мемных Рангов**:
  - 🥔 *Полный Скуф из Одноклассников*
  - 🥱 *Нормис Обыкновенный*
  - 🗿 *Базированный Гигачад*
  - 👑 *Абсолютный Повелитель Брейнрота (Чозабретто)*
- 🚀 **Кнопка «Поделиться в Telegram»**: мгновенная отправка результата и статуса в любой чат или сторис.
- 📖 **Мемопедия**: встроенная энциклопедия всех 25+ мемов с подробным лором, происхождением и кнопкой тестового басового удара!
- 🎨 **Красочные SVG-иллюстрации**: никакого риска битых внешних картинок (404), всё встроено прямо в код.

## 📱 Как запустить в виде настоящего Telegram Mini App

Для того чтобы приложение открывалось внутри Telegram, ему требуется ссылка с протоколом **HTTPS**.

### Шаг 1. Получение HTTPS ссылки

**Вариант А: Быстрый туннель для тестов (бесплатно)**
Если запущен локальный сервер на порту 3000:
```bash
npx localtunnel --port 3000
# или
ngrok http 3000
```
Ты получишь публичную ссылку вида `https://bright-cat-99.loca.lt` или `https://xxxx.ngrok-free.app`.

**Вариант Б: Бесплатный хостинг (навсегда)**
- Загрузи файлы на **GitHub Pages**:
  1. Создай репозиторий на GitHub и загрузи файлы (`index.html`, `style.css`, `app.js`, `memes-data.js`, `audio.js`).
  2. В настройках репозитория (Settings -> Pages) включи `Deploy from a branch (main)`.
  3. Твоя ссылка: `https://твой-логин.github.io/имя-репозитория/`.
- Либо перетяни папку в **Vercel** или **Netlify** — это займет 30 секунд.

---

### Шаг 2. Создание бота в Telegram через @BotFather

1. Открой Telegram и найди бота [@BotFather](https://t.me/BotFather).
2. Отправь команду `/newbot`, придумай имя и username (например, `MemeMasterQuizBot`).
3. Скопируй полученный **BOT_TOKEN**.
4. Включи Web App кнопку для меню:
   - Отправь `/mybots` -> выбери своего бота.
   - Нажми **Bot Settings** -> **Menu Button** -> **Configure menu button**.
   - Отправь ссылку на свой Web App (полученную в Шаге 1).
   - Введи текст для кнопки: `🎮 Чё за мем?`.
5. *(Опционально)* Можно создать инлайн Mini App команду через `/newapp` в @BotFather.

---

### Шаг 3. Запуск бота-помощника

В проекте уже есть готовые скрипты бота (на выбор: Python или Node.js):

#### Запуск на Python:
```bash
# Укажи токен и URL:
set BOT_TOKEN=твой_токен_от_BotFather
set WEB_APP_URL=https://твоя-https-ссылка.com
python bot.py
```

#### Запуск на Node.js:
```bash
set BOT_TOKEN=твой_токен_от_BotFather
set WEB_APP_URL=https://твоя-https-ссылка.com
node bot.js
```

Теперь любой пользователь, написавший твоему боту `/start`, получит красивое приветствие и кнопку для мгновенного запуска игры в окне Telegram!

## 🛠️ Как добавить свои мемы

Все мемы хранятся в файле [`memes-data.js`](file:///C:/Users/UserUA/.gemini/antigravity/scratch/guess-the-meme-twa/memes-data.js).

Чтобы добавить новый мем, просто допиши в массив `MEME_DATABASE` объект:
```javascript
{
  id: "my_cool_meme",
  category: "brainrot", // brainrot | zoomer | classic | legend
  title: "Название мема",
  question: "В чём суть этого шедевра?",
  visual: {
    emoji: "🗿",
    bgGradient: "linear-gradient(135deg, #8b5cf6, #ec4899)",
    caption: "Цитата или подпись под мемом"
  },
  options: [
    "Правильный смешной ответ",
    "Неправильный ответ 1",
    "Неправильный ответ 2",
    "Неправильный ответ 3"
  ],
  correctIndex: 0,
  fact: "Пояснение из мемологии (почему это стало мемом)",
  punchline: "Финальная шутка или панчлайн"
}
```

Приятной игры и побольше базы в ленте! 🗿🔥
